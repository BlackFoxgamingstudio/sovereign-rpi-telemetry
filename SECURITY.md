# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Sovereign Biz Box team takes security seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please send an encrypted email to `russell@sovereignbizbox.io` with:
1. A description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal proof of concept.
3. Your proposed remediation (if available).

We will acknowledge receipt within 24 hours and provide a fix within 72 hours for critical vulnerabilities.
